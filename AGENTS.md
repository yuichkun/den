# den development

The source of scope is GEN-610 and the linked den specifications. This repository is a fresh TypeScript/unworklet package; do not restore the retired Rust/WASM stack.

Use Node 24 and npm. Run `npm ci`, `npm run check`, and `npm test` before review. The gate must install the packed package in an isolated consumer and verify actual rendering. Keep unworklet at 0.4.1. Do not patch upstream or introduce parameter, snapshot, routing, loader, or test frameworks.

Keep package exports, lockfile, shared contracts, and consumer changes under one integration owner. DSP lanes start after independent entry-contract review. No registry publication. Preserve Git history; use branches and PRs. Independent review and exact-head CI are required before merge.

Audio generated by tests is CANDIDATE, never an approved golden. Preserve independent numerical assertions; never update expected audio to make CI pass. Human approval is recorded separately against source/audio hashes.
